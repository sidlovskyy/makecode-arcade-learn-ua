# КодКвест

«КодКвест» — безплатний україномовний курс Microsoft MakeCode Arcade для дітей 10–12 років. Він проводить учня через 24 покрокові місії у 6 рівнях: від першого спрайта й керування до TypeScript і власної завершеної гри.

Це статичний React-застосунок без бекенду, реєстрації, реклами й аналітики. Уроки містять короткі пояснення, 5–8 практичних кроків, самостійне випробування та мінітест. MakeCode відкривається окремо на офіційному сайті Microsoft.

## Локальний запуск

Потрібен сучасний Node.js із npm. Виконуйте команди з цієї директорії:

```bash
npm install
npm run dev
```

Vite покаже локальну адресу сайту. Для відтворюваного встановлення залежностей із `package-lock.json` використовуйте `npm ci`.

## Перевірка і збірка

```bash
npm run typecheck  # перевірка TypeScript
npm test           # усі автоматизовані тести
npm run build      # production-збірка
npm run check      # typecheck + тести + збірка
```

Готовий статичний сайт з’явиться у `dist/`. Цю папку генерує Vite — не редагуйте її вручну й не додавайте до Git.

## Як влаштований курс

- `src/curriculum/` — типізований зміст шести рівнів і 24 місій.
- `src/components/` — навчальна мапа, урок, кроки, випробування, тести й нагороди.
- `src/progress/` — локальне збереження та відновлення прогресу.
- `src/styles/` — дизайн-система Pixel Neon і адаптивні стилі.
- `src/assets/` — власна ілюстрація курсу.

Маршрути використовують hash: `#/` відкриває мапу, а `#/lesson/<slug>` — конкретну місію. Тому прямі посилання працюють і на простому статичному хостингу без серверної маршрутизації.

## Приватність прогресу

Прогрес зберігається лише в `localStorage` поточного браузера під ключем `kodkvest.progress.v1`. Сайт не створює облікових записів, не збирає персональних даних і не синхронізує прогрес між пристроями. Очищення даних браузера видалить прогрес. Якщо сховище заблоковане, уроки працюють у межах відкритої сесії та показують попередження.

Єдиний зовнішній перехід під час навчання — видиме посилання на офіційні сторінки `https://arcade.makecode.com/`.

## Статичне розміщення

1. Виконайте `npm ci` і `npm run build`.
2. Завантажте вміст `dist/` на GitHub Pages, Cloudflare Pages, Netlify або інший статичний хостинг.
3. Публікуйте `dist/index.html` разом із усією папкою `dist/assets/`.

У Vite задано `base: './'`, тому посилання на JavaScript, CSS та ілюстрацію у production-збірці відносні й працюють у вкладеному шляху, зокрема в GitHub Pages. Для Pages найзручніше використати GitHub Actions: команда збірки — `npm ci && npm run build`, папка для публікації — `dist` (або `site/dist`, якщо ця директорія є частиною більшого репозиторію).

GitHub Gist може зберігати вихідні або зібрані файли, але сам не показує React-застосунок як звичайний сайт. Для робочої вебадреси використовуйте GitHub Pages чи інший статичний хостинг. Сторонні сервіси, що відображають Gist як сайт, додають окрему залежність і не є рекомендованим способом публікації дитячого навчального проєкту.

## Фінальна перевірка перед публікацією

- [ ] `npm ci` і `npm run check` завершуються без помилок.
- [ ] У `dist/` є `index.html`, хешовані JS/CSS та оптимізована WebP-ілюстрація; немає source map, секретів або серверного коду.
- [ ] На ширинах desktop, tablet і mobile немає горизонтального прокручування чи перекритих елементів.
- [ ] Новий учень починає з місії 1; після оновлення сторінки незавершений урок відновлюється.
- [ ] Видно всі 24 місії; пошук, фільтр і скидання фільтрів працюють.
- [ ] Неправильна й правильна відповіді мінітесту мають зрозумілий зворотний зв’язок; завершення місії додає XP один раз.
- [ ] Невідомий slug показує «Місії не знайдено» та посилання назад до мапи.
- [ ] Усі дії доступні лише з клавіатури, focus добре видно, а режим reduced motion не має зайвих анімацій.
- [ ] За заблокованого `localStorage` курс лишається доступним і не обіцяє збереження прогресу.
- [ ] Кожне посилання MakeCode веде на `https://arcade.makecode.com/` і відкривається безпечно в новій вкладці.
